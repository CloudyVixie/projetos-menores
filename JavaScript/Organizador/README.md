# Organizador

O Organizador é uma página simples para colocar palavras ou nomes em ordem alfabética. Basta inserir os itens, separar cada um por vírgula ou quebra de linha e organizar a lista.

## Como era antes da alteração

Antes da atualização visual, o site já tinha sua função principal: receber texto em uma área de entrada, separar os itens por vírgulas ou quebras de linha, ordenar os itens alfabeticamente e mostrar o resultado em uma lista. Também já existia a opção de copiar o resultado.

## Por que usei IA

A IA foi utilizada apenas para trabalhar na estilização e na apresentação visual do site. A intenção foi deixar a interface mais organizada, agradável e fácil de usar, sem atribuir à IA a criação da proposta ou da funcionalidade original do Organizador.

## Como usar

1. Digite ou cole os nomes e palavras na área de entrada.
2. Separe os itens por vírgulas ou coloque cada item em uma linha.
3. Confira a lista organizada alfabeticamente.
4. Use a opção de copiar para levar o resultado para outro lugar.

## Tecnologias

- HTML
- CSS
- JavaScript
