# CalculadoraProbabilidadeEventosIndependentes

Calculadora de probabilidade para estimar quantas tentativas são necessárias para atingir uma probabilidade acumulada de sucesso. Pratica funções, laços, validação de entradas, try/except e os módulos math, time e os.

## Execução

Execute o arquivo principal com Python:

    python CalculadoraProbabilidadeEventosIndependentes.py

## Tecnologia

- Python
