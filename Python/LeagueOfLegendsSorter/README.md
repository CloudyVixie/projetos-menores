# LeagueOfLegendsSorter

Sorteador de campeões de League of Legends por rota. Permite escolher Top, Jungle, Mid, ADC, Support, todas as rotas ou uma rota aleatória. Pratica listas, dicionários, funções e o módulo random.

## Execução

Execute o arquivo principal com Python:

    python LeagueOfLegendsSorter.py

## Tecnologia

- Python
