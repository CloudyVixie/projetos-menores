# ListaComprasPOO

Lista de compras desenvolvida para praticar Programação Orientada a Objetos. Utiliza a classe Produto, listas de objetos, métodos, atributos e gravação dos produtos e do valor total em um arquivo TXT.

## Execução

Execute o arquivo principal com Python:

    python ListaComprasPOO.py

## Tecnologia

- Python
