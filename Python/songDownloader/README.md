# songDownloader

Script para baixar músicas ou playlists a partir de URLs do YouTube utilizando yt-dlp. Pratica funções, dicionários de configuração, pathlib e interação com bibliotecas externas.

## Execução

Execute o arquivo principal com Python:

    python songDownloader.py

## Tecnologia

- Python

### Dependência

Instale o yt-dlp com:

    pip install yt-dlp
